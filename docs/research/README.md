# Research Notes

First-class wiki input alongside [[Raw Sources|docs/raw]].

Unlike raw sources, research notes are living documents that evolve as investigation deepens.
The `ingest` operation reads from this directory and updates wiki pages accordingly.

## Conventions

- One file per investigation, experiment, or design exploration.
- Preferred filename pattern: `YYYY-MM-DD-topic.md` or `topic.md`.
- Use consistent section headings for scannable structure:

```markdown
## Summary
## Findings
## Open Questions
## See Also
```

> [!TIP] What belongs here?
> Profiling runs, bug post-mortems, design explorations, spike results, reading notes on papers — anything investigative that you authored yourself.
